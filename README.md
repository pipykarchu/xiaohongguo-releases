# 小红果 Windows 下载

这是小红果的公开下载与更新仓库，只发布程序包和更新信息，不包含私有源码或发布者个人记录。

## 下载与使用

[下载最新版本](https://github.com/pipykarchu/xiaohongguo-releases/releases/latest)

下载 Release 中的 `xiaohongguo-版本号-windows-x64.zip`（不是 GitHub 自动生成的 Source code 压缩包）。需要 Windows 10/11 64 位系统。

完整解压到自己有写入权限的文件夹，双击 `hongguojian.exe`。可运行 `create-shortcut.vbs` 创建“小红果”桌面快捷方式。不要从 ZIP 内直接运行。

## 更新

进入「设置与备份 → 检查软件更新」，检查新版后选择「下载并更新」，下载校验完成后确认安装并重启。

首次在新电脑上使用没有发布者的追剧、历史、账号或配对记录。更新保留每位使用者自己在该 Windows 用户目录中的记录。

程序通过 HTTPS 从此仓库下载，核对 SHA-256 后安装。未使用 Windows 代码签名，系统可能显示未知发布者，请不要关闭系统安全防护。网络无法访问 GitHub 时可以稍后重试，当前版本不会因为检查失败而被删除。
